# 📱 Интернет-магазин электроники Bylance (Алматы)

Современный и быстрый интернет-магазин оригинальной электроники (**Apple**, **Dyson**, **фототехника и умные гаджеты**) в Алматы.

### Основные возможности:
- **4 способа расчёта для каждого товара**: Kaspi рассрочка (0-0-12 / 0-0-24), Halyk рассрочка, Акционная спеццена, Скидка при оплате наличными.
- **Интерактивные конфигураторы**: выбор типа SIM-карты (eSIM / физическая SIM) и объёма памяти (кнопка видна всегда, даже при одном варианте объёма).
- **Программа Trade-In**: быстрый переход к онлайн-оценке старого iPhone на сайте и консультация в WhatsApp.
- **Умная корзина**: возможность собрать заказ с разными способами оплаты для каждого товара и мгновенно отправить готовую спецификацию менеджеру в WhatsApp.
- **Тёмная и светлая тема**: автоматическое сохранение выбора покупателя.

## 🛠 Где и что менять в коде

### 1. Контакты, телефоны, WhatsApp и адрес магазина
**Файл:** `src/data/prices.ts` (строки 10–21)
Найдите объект `SITE_INFO`:
```ts
export const SITE_INFO = {
  shopName: "Bylance",                                    // Название магазина
  city: "Алматы",                                         // Город
  logoPath: "/logo.svg",                                  // Путь к логотипу
  whatsapp: "77765293916",                                // Номер для отправки заказов в WhatsApp (только цифры с 7)
  whatsappFormatted: "+7 (776) 529-39-16",                // Красивое отображение номера на сайте
  telegram: "bylance",                                    // Юзернейм канала Telegram (без @)
  gis: "https://2gis.kz/almaty",                          // Ссылка на 2ГИС карточку магазина
  address: "г. Алматы, пр. Абылай хана (точный адрес уточняйте в WhatsApp)",
  hours: "Ежедневно 10:00–20:00",                         // График работы офиса
  roundTo: 1000,
};
```
> 💡 **Важно**: При смене номера в поле `whatsapp` изменится номер получателя для всех кнопок «Заказать в WhatsApp», оценки Trade-In и отправки корзины.

**Файл:** `src/App.tsx`
Ссылка используется в двух местах:

   ```tsx

   ```
2. **В блоке FAQ** (около строки 1400):
   ```tsx
   <a href="https://bylance.kz/trade-in" target="_blank" ...>
   ```
Замените `https://bylance.kz/trade-in` на нужный вам URL онлайн-калькулятора или формы.

### 3. Товары, цены, объёмы памяти и SIM-карты
**Файл:** `src/data/prices.ts` (массив `PRODUCT_MODELS`)

Каждый товар описан следующим объектом:
```ts
{
  id: 'model-ip17',                        // Уникальный ID модели
  name: 'iPhone 17',                       // Название товара
  category: 'apple',                       // Категория: 'apple' | 'dyson' | 'other'
  subcategory: 'iPhone 17',                // Подкатегория для фильтра
  warranty: '1 год официальной гарантии', // Текст гарантии
  image: PRODUCT_IMAGES.iphone,           // Фотография
  simOptions: ['ESIM', 'SIM'],             // Варианты SIM: ['ESIM', 'SIM'] или не указывать
  storageOptions: ['256 ГБ'],              // Доступные объёмы памяти
  variants: [
    {
      id: '17-esim-256',
      fullName: 'iPhone 17 (ESIM) 256 ГБ',
      simType: 'ESIM',
      storage: '256 ГБ',
      prices: {
        kaspi: 600000,  // Цена в рассрочку Kaspi
        halyk: 625000,  // Цена в рассрочку Halyk
        promo: 520000,  // Акционная спеццена
        cash: 500000,   // Цена со скидкой за наличный расчет
      },
    },
    // ... другие варианты (SIM, другие объемы памяти)
  ]
}
```
- Чтобы изменить цену: просто укажите новые числа в объекте `prices` для нужного варианта.
- Чтобы добавить память (например, 512 ГБ): добавьте `'512 ГБ'` в `storageOptions` и добавьте соответствующий объект в массив `variants`.

### 5. Часто задаваемые вопросы (FAQ)
**Файл:** `src/App.tsx` (массив `FAQ_LIST`, строки 125–170)
Каждый вопрос оформлен в виде:
```ts
{
  id: 'faq-trade-in',
  question: 'Как работает программа Trade-In и какие устройства принимаются?',
  answer: 'В магазине Bylance по программе Trade-In принимаются исключительно оригинальные Apple iPhone!\n\n• Оценка в офисе...',
  hasTradeInLinks: true, // Включает кнопки быстрой онлайн-оценки и WhatsApp
}
```
Вы можете свободно редактировать текст вопросов и ответов, а также добавлять новые элементы в массив `FAQ_LIST`.

### 6. Шапка сайта и навигация
**Файл:** `src/App.tsx` (блок `<header>`, строки 550–610)
- **Логотип и название**: отображаются автоматически из `SITE_INFO.shopName` и `SITE_INFO.logoPath`.
- **Ссылки быстрой навигации**: «Каталог» (`#catalog`), «FAQ» (`#faq`), иконка локации «Контакты» (`#contacts`).
- **Переключатель темы**: переключает светлую/тёмную тему с сохранением в `localStorage`.

---

### 7. Плашки-якоря в главном блоке (Hero)
**Файл:** `src/App.tsx` (строки 820–860)
Каждая плашка содержит синюю акцентную полоску снизу и стрелку вниз `↓`:
1. *Рассрочка Kaspi и Halyk* — активирует режим Kaspi и скроллит к каталогу.
2. *Специальные акционные цены* — активирует акционный режим и скроллит к каталогу.
3. *Максимальная скидка за наличную оплату* — активирует режим наличного расчёта и скроллит к каталогу.
4. *Программа Trade-In (обмен)* — скроллит к блоку Trade-In.
