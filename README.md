# 📱 Интернет-магазин электроники Bylance (Алматы)

Современный и быстрый интернет-магазин оригинальной электроники (**Apple**, **Dyson**, **фототехника и умные гаджеты**) в Алматы.

### Основные возможности:
- **Основательница магазина**: блок об Аружан Жеткерген с прямыми ссылками на TikTok (@_zaag_), Instagram (@zaagaru) и @bylance_kz.
- **Быстрый доступ к каталогу**: категории и товары открываются сразу на первом экране.
- **Программа Trade-In вверху каталога**: быстрый переход к онлайн-оценке старого iPhone на сайте и консультация в WhatsApp.
- **Глобальный и индивидуальный пересчёт цен**: кнопки вверху каталога пересчитывают весь каталог, а на каждой карточке кнопка оплаты закреплена внизу на одной высоте.
- **Интерактивные конфигураторы**: выбор типа SIM-карты (eSIM / физическая SIM) и объёма памяти.
- **Умная корзина**: возможность собрать заказ с разными способами оплаты для каждого товара и мгновенно отправить готовую спецификацию менеджеру в WhatsApp.
- **Тёмная и светлая тема**: автоматическое сохранение выбора покупателя.

## 🛠 Где и что менять в коде

### 1. Контакты, телефоны, WhatsApp и адрес магазина
**Файл:** `src/data/prices.ts` (строки 10–21)
Найдите объект `SITE_INFO`:
```ts
export const SITE_INFO = {
  shopName: "Bylance",                                    // Название магазина
  city: "Алматы",                                         // Город
  logoPath: "/logo.svg",                                  // Путь к логотипу
  whatsapp: "77765293916",                                // Номер для отправки заказов в WhatsApp (только цифры с 7)
  whatsappFormatted: "+7 (776) 529-39-16",                // Красивое отображение номера на сайте
  telegram: "bylance",                                    // Юзернейм канала Telegram (без @)
  gis: "https://2gis.kz/almaty",                          // Ссылка на 2ГИС карточку магазина
  address: "г. Алматы, пр. Абылай хана (точный адрес уточняйте в WhatsApp)",
  founder: {
    name: "Аружан Жеткерген",
    role: "Основательница магазина Bylance",
    image: "/aruzhan.jpg",                                // Фотография: поместите файл в public/aruzhan.jpg или укажите ссылку
    instagram: "zaagaru",
    tiktok: "_zaag_",
    shopInstagram: "bylance_kz",
  },
};
```
> 💡 **Фото основательницы**: положите фото в папку `/public/aruzhan.jpg` (или укажите ссылку на изображение в `image`). Рамка фотографии оформлена с эффектом градиента и автоматическим аватаром-заглушкой.

### 3. Товары, цены, объёмы памяти и SIM-карты
**Файл:** `src/data/prices.ts` (массив `PRODUCT_MODELS`)

Каждый товар описан следующим объектом:
```ts
{
  id: 'model-ip17',                        // Уникальный ID модели
  name: 'iPhone 17',                       // Название товара
  category: 'apple',                       // Категория: 'apple' | 'dyson' | 'other'
  subcategory: 'iPhone 17',                // Подкатегория для фильтра
  warranty: '1 год официальной гарантии', // Текст гарантии
  image: PRODUCT_IMAGES.iphone,           // Фотография
  simOptions: ['ESIM', 'SIM'],             // Варианты SIM: ['ESIM', 'SIM'] или не указывать
  storageOptions: ['256 ГБ'],              // Доступные объёмы памяти
  variants: [
    {
      id: '17-esim-256',
      fullName: 'iPhone 17 (ESIM) 256 ГБ',
      simType: 'ESIM',
      storage: '256 ГБ',
      prices: {
        kaspi: 600000,  // Цена в рассрочку Kaspi
        halyk: 625000,  // Цена в рассрочку Halyk
        promo: 520000,  // Акционная спеццена
        cash: 500000,   // Цена со скидкой за наличный расчет
      },
    },
    // ... другие варианты (SIM, другие объемы памяти)
  ]
}
```
- Чтобы изменить цену: просто укажите новые числа в объекте `prices` для нужного варианта.
- Чтобы добавить память (например, 512 ГБ): добавьте `'512 ГБ'` в `storageOptions` и добавьте соответствующий объект в массив `variants`.

### 4. Выбор цвета товара по маленьким картинкам (превью)
**Файл:** `src/data/prices.ts` (строки 110–165 и массив `PRODUCT_MODELS`)

На карточках товаров настроен выбор цвета по мини-фотографиям. При клике на мини-картинку меняется главное фото товара, отображается выбранный цвет, а при заказе в 1 клик через WhatsApp или добавлении в корзину название цвета автоматически передаётся менеджеру!

Готовые наборы цветов объявлены в начале `src/data/prices.ts`:
- `IPHONE_PRO_COLORS` (Desert Titanium, Natural Titanium, White Titanium, Black Titanium)
- `IPHONE_BASE_COLORS` (Ultramarine, Teal, Pink, White, Black)
- `IPAD_COLORS`, `MACBOOK_COLORS`, `WATCH_COLORS`, `DYSON_COLORS`

**Как добавить или заменить свои картинки цветов:**
1. Вы можете заменить ссылку `image` в готовых наборах в `src/data/prices.ts`:
   ```ts
   export const IPHONE_PRO_COLORS: ProductColor[] = [
     {
       id: 'desert',
       name: 'Desert Titanium',
       hex: '#c5b39b',
       image: '/images/iphone_desert.jpg', // 👈 Ваша картинка (из папки public/ или ссылка https://)
     },
     {
       id: 'natural',
       name: 'Natural Titanium',
       hex: '#9f9b96',
       image: '/images/iphone_natural.jpg',
     },
   ];
   ```
2. Либо настроить индивидуальный массив `colorOptions` для конкретного товара прямо в `PRODUCT_MODELS`:
   ```ts
   {
     id: 'model-ip18p',
     name: 'iPhone 18 Pro',
     colorOptions: [
       { id: 'my-color-1', name: 'Черный титан', image: 'https://...', hex: '#333333' },
       { id: 'my-color-2', name: 'Белый титан',  image: 'https://...', hex: '#f0f0f0' },
     ],
     // ...
   }
   ```
> 💡 Если картинка ещё не загружена или ссылка не найдена, мини-плашка автоматически покажет аккуратный кружок с цветом (`hex`), сохранив идеальный внешний вид карточки.

### 5. Автоматическое переключение тёмной/светлой темы по системе устройства
Тема сайта по умолчанию **автоматически следует системной теме телефона покупателя**:
- Если на телефоне включена **тёмная тема**, сайт мгновенно открывается в тёмном оформлении.
- Если на телефоне **светлая тема**, сайт открывается в светлом оформлении.
- При переключении темы в настройках операционной системы (iOS Control Center / Android) сайт реагирует в реальном времени.
- В шапке также остаётся ручная кнопка (солнце/луна) для быстрого переключения в 1 клик.

### 7. Плашки-якоря в главном блоке (Hero)
**Файл:** `src/App.tsx` (строки 820–860)
Каждая плашка содержит синюю акцентную полоску снизу и стрелку вниз `↓`:
1. *Рассрочка Kaspi и Halyk* — активирует режим Kaspi и скроллит к каталогу.
2. *Специальные акционные цены* — активирует акционный режим и скроллит к каталогу.
3. *Максимальная скидка за наличную оплату* — активирует режим наличного расчёта и скроллит к каталогу.
4. *Программа Trade-In (обмен)* — скроллит к блоку Trade-In.
